# suivi-prets

Tableau de bord interactif de suivi de prêts amortissables (FR / ქართული).

🔗 **Démo en ligne :** https://ldws123.github.io/suivi-prets/

> ℹ️ Version **publique et anonymisée** : aucune donnée personnelle
> (pas de noms, pas de numéros de prêt). Seuls montants, taux, dates et
> échéanciers sont affichés, à titre de démonstration.

## Fonctionnalités

- **Curseur temporel** : état des prêts à n'importe quelle date.
- **Bouton « État actuel »** : retour à aujourd'hui (date réelle, auto).
- Capital restant dû, capital remboursé, intérêts payés/restants,
  assurance, mensualité, prochaine échéance.
- **Bascule de langue** Français ↔ Géorgien (ქართული).
- Graphique d'évolution (capital restant / intérêts cumulés).
- 100 % statique, sans dépendance, fonctionne hors-ligne.

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | L'application (HTML + CSS + JS) |
| `data.js` | Données d'amortissement (anonymisées) |
